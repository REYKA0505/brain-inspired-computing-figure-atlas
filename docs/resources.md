# 科研图片资源索引

收录可浏览或检索科研论文图、学术图例及科研插画的网站与图集。资源类型不同，具体内容和许可请查看各自页面。

## 类脑计算预印本

在网页图库的「论文来源」中选择 `arXiv` 或 `bioRxiv`，可按版本浏览已收录图件。[选录清单](../data/curated-figures.json)保留图号、原始图注和许可出处。

| 方向 | 图源与团队 |
| --- | --- |
| 脉冲网络学习 | FMI Basel 与巴塞尔大学的[代理梯度分析](https://arxiv.org/abs/2404.14964v3)，覆盖梯度示意、闭合路径检验和分类结果。 |
| 循环网络训练 | 哥伦比亚大学的[随机反馈学习](https://www.biorxiv.org/content/10.1101/458570v1)和剑桥大学、纽约大学团队的[长时依赖任务训练](https://pmc.ncbi.nlm.nih.gov/articles/PMC10592728/)。 |
| 神经环路与决策 | [Chen 等人的循环网络策略模型](https://pmc.ncbi.nlm.nih.gov/articles/PMC13104915/)和 IBL 团队的[单神经元内在时间尺度](https://pmc.ncbi.nlm.nih.gov/articles/PMC12407892/)。 |
| 连接组与脑成像 | [MICrONS 视觉皮层连接组](https://www.biorxiv.org/content/10.1101/2021.07.28.454025v2)展示成像和神经元重建流程，[Natural Scenes Dataset](https://www.biorxiv.org/content/10.1101/2021.02.22.432340v1)展示 fMRI 去噪、空间分辨率与模型预测。 |
| 神经形态硬件 | TU Dresden 与曼彻斯特大学的 [SpiNNaker2](https://arxiv.org/abs/2607.24396v1)，以及英特尔实验室等团队的 [Loihi 2](https://arxiv.org/abs/2503.18002v2)。 |
| 基准评测 | [NeuroBench](https://arxiv.org/abs/2304.04640v5) 联合团队的评测系统分类和布置图。 |
| 延伸阅读 | [SpikingJelly](https://arxiv.org/abs/2310.16620) 的脉冲网络软件生态示例，[Winding 等人的昆虫脑连接组](https://www.biorxiv.org/content/10.1101/2022.11.28.516756v1) 展示跨尺度连接与回路布局。 |
