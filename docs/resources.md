# 科研图片资源索引

收录可浏览或检索科研论文图、学术图例及科研插画的网站与图集。资源类型不同，具体内容和许可请查看各自页面。

[网页资源导航](../resources.html) · [网页图库](../index.html) · [主题图墙](index.md)

## 论文图像与学术图集

| 资源 | 收录内容 |
| --- | --- |
| [SCI Figure Gallery](https://chutj.github.io/gallery/) | 真实论文图集，提供图型、关键词、图注、来源和许可等信息。 |
| [Plottie](https://plottie.art/) | 论文图像检索与浏览平台，可按关键词、图型和来源查看图例。 |
| [PaperFigure](https://paperfigure.net/) | 论文图片检索平台，主要收录计算机科学和人工智能领域的图例。 |
| [Awesome Academic Figures](https://doczbs.github.io/Awesome-Academic-Figures/) · [项目主页](https://github.com/DocZbs/Awesome-Academic-Figures) | 学术论文图像合集，包含人工智能、机器人、计算机视觉等方向的图例。 |
| [Top-Conf Paper Figure Gallery](https://qwdwqfwq.github.io/topconf-paper-figure-gallery/) · [项目主页](https://github.com/qwdwqfwq/topconf-paper-figure-gallery) | 汇集人工智能与计算机领域会议论文的 Figure 1 和 Teaser 图。 |
| [Awesome Scientific Figure](https://nehsgnail.github.io/awesome-scientific-figure/) · [项目主页](https://github.com/nehSgnaiL/awesome-scientific-figure) | 按地图、散点图、箱线图等类别整理的论文图例。 |
